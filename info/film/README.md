# Film photos

Drop film scans in this folder (`.jpg`, `.png` or `.webp`). They show up in the **Film** card, opened from the instant camera on the bed.

- **Order:** photos are sorted by file name, so prefix them with numbers: `01-…`, `02-…`.
- **Caption:** the file name, without the number prefix, becomes the caption: `02-blacksburg-snow.jpg` shows as "blacksburg snow".
- **Size:** keep scans around 1600px on the long side (webp is smallest) so the page stays quick.
